# Gateway Backlog

当前版本确定不做的事项，留作未来参考。

---

## 功能 Backlog

### 身份鉴权

- **描述**: 添加 API Key 或其他认证机制
- **原因**: 当前为本地服务，无需鉴权
- **触发条件**: 如果未来需要暴露到公网或多用户场景

### 异步队列

- **描述**: 引入消息队列（如 Redis）实现异步处理
- **原因**: 当前请求量小，同步处理足够
- **触发条件**: 采集量显著增加，或需要处理复杂的清洗逻辑

### 批量采集接口

- **描述**: 支持单次请求提交多条数据
- **原因**: 当前单条提交满足需求
- **触发条件**: Python Collector 需要批量提交以提升效率

### 内容更新检测

- **描述**: 检测已采集内容是否有更新
- **原因**: "忽略更新，只采集一次"是核心设计决策
- **触发条件**: 需要追踪内容变化（如价格监控场景）

### 可扩展 Metadata

- **描述**: 支持自定义 metadata 字段
- **原因**: 当前字段已满足需求
- **触发条件**: 出现无法通过现有字段表达的元信息

---

## 技术优化 Backlog

### Web UI 管理界面

- **描述**: 提供 Web 界面查看采集统计、管理数据
- **原因**: 当前通过 CLI 和文件系统管理
- **触发条件**: 采集量增加后需要更好的可视化

### 采集重试机制

- **描述**: Readability 失败或写入失败时的重试
- **原因**: 当前直接返回错误
- **触发条件**: 出现频繁的临时性失败

### 增量备份

- **描述**: 定期备份 dedup.sqlite 和 raw/ 目录
- **原因**: Git 已提供版本控制
- **触发条件**: 数据量大到 Git 不适合管理

---

## 开放性问题

### URL 规范化边界

- **问题**: 某些平台的 URL 规则可能变化，规范化规则需要持续维护
- **当前处理**: 按已知规则处理，未知情况保持原样

### Readability 提取失败

- **问题**: 部分网页结构不适合 Readability 提取（如 SPA、付费墙）
- **当前处理**: 降级为存储原始 HTML 或提示采集端预处理

### QMD Collection 动态创建

- **问题**: 新的 source 类型是否自动创建 Collection
- **当前处理**: 手动运行初始化脚本
